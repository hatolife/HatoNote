# 1画面プレゼンテーション

## 表示

- SCR-PRESENT-001: スライド文書から開始できる。
- SCR-PRESENT-002: 先頭ページから開始できる。
- SCR-PRESENT-003: 現在ページから開始できる。
- SCR-PRESENT-004: 発表中はスライドを可能な限り大きく表示する。
- SCR-PRESENT-005: スライドの縦横比を維持する。
- SCR-PRESENT-006: スライド外側は資料設定の余白色で表示する。
- SCR-PRESENT-007: 不要な前後移動ボタンを常時スライド上へ重ねて表示しない。
- SCR-PRESENT-008: 全画面表示中はHatoNoteのタイトルバーを表示しない。

## ページ移動

- SCR-PRESENT-010: 右矢印キーで次ページへ移動する。
- SCR-PRESENT-011: 左矢印キーで前ページへ移動する。
- SCR-PRESENT-012: Enterキーで次ページへ移動する。
- SCR-PRESENT-013: マウスホイール1ノッチを1ページ移動として扱う。
- SCR-PRESENT-014: 1回のホイール操作で複数ページ飛ばないよう入力を制御する。
- SCR-PRESENT-015: 横長画面では右側余白のクリックで次ページへ移動できる。
- SCR-PRESENT-016: 横長画面では左側余白のクリックで前ページへ移動できる。

## 終了

- SCR-PRESENT-020: Escキーでプレゼンテーションを終了する。
- SCR-PRESENT-021: 右クリックでプレゼンテーションを終了する。
- SCR-PRESENT-022: 終了後は開始前のメイン画面へ戻る。
