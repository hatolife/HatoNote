# mdBook設定画面

## 表示

- SCR-BOOKSET-001: mdBook文書から表示する。
- SCR-BOOKSET-002: `book.toml` の現在内容を表示する。
- SCR-BOOKSET-003: 表示状態から編集状態へ切り替えられる。

## 編集

- SCR-BOOKSET-010: `book.toml` を直接編集できる。
- SCR-BOOKSET-011: 無効な設定を確定しない。
- SCR-BOOKSET-012: 設定の検証エラーを画面内に表示する。
- SCR-BOOKSET-013: 有効な設定を確定すると文書内の `book.toml` を更新する。
- SCR-BOOKSET-014: 閉じるだけでは未確定の編集を適用しない。
