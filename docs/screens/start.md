# 開始画面

## 表示

- SCR-START-001: 起動時に開く文書が指定されていない場合は開始画面を表示する。
- SCR-START-002: 開始画面では文書本文、ページ一覧、編集ツールを表示しない。
- SCR-START-003: 開始画面に製品名 `HatoNote` を表示する。
- SCR-START-004: 開始画面から既存文書を開ける。
- SCR-START-005: 開始画面内で新規文書を作成でき、別の新規文書作成ダイアログを使用しない。
- SCR-START-006: 開始画面から作業データの復旧画面を開ける。
- SCR-START-007: 開始画面に `ここに .md / .mdz をドロップ` と表示する。

## 文書を開く

- SCR-START-010: `.md` を開くと現在のウィンドウでメイン画面へ遷移する。
- SCR-START-011: `.markdown` を開くと現在のウィンドウでメイン画面へ遷移する。
- SCR-START-012: `.mdz` を開くと現在のウィンドウでメイン画面へ遷移する。
- SCR-START-013: 対応文書のD&DはDND仕様に従う。
- SCR-START-014: 文書を開くためだけに新しいウィンドウを作成しない。

## 新規文書

- SCR-START-020: 新規文書作成UIは単一Markdown、通常MDZ、mdBook、スライドの4列で表示する。
- SCR-START-021: 列の順序は左から `Markdown`、`MDZ`、`mdBook`、`スライド` とする。
- SCR-START-022: 各列の最初に空の文書を作成する操作を表示する。
- SCR-START-023: 各列に利用方法を簡単に説明する内容入りの初期文書を作成する操作を表示する。
- SCR-START-024: 文書種別固有の追加テンプレートがある場合は同じ列の下へ表示する。
- SCR-START-025: 存在しないテンプレートのための空ボタンを表示しない。
- SCR-START-026: メイン画面から新規文書操作を開始した場合も同じ開始画面の新規文書UIを使用する。
- SCR-START-027: メイン画面から開始画面を開いた場合は元の文書へ戻れる操作を表示する。
