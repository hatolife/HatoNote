# 開始画面

## 表示

- SCR-START-001: 起動時に開く文書が指定されていない場合は開始画面を表示する。
- SCR-START-002: 開始画面では文書本文、ページ一覧、編集ツールを表示しない。
- SCR-START-003: 開始画面に製品名 `HatoNote` を表示する。
- SCR-START-004: 開始画面から既存文書を開ける。
- SCR-START-005: 開始画面から新規文書作成画面を開ける。
- SCR-START-006: 開始画面から作業データの復旧画面を開ける。
- SCR-START-007: 開始画面にファイルD&Dが利用できることを表示する。

## 文書を開く

- SCR-START-010: `.md` を開くと現在のウィンドウでメイン画面へ遷移する。
- SCR-START-011: `.markdown` を開くと現在のウィンドウでメイン画面へ遷移する。
- SCR-START-012: `.mdz` を開くと現在のウィンドウでメイン画面へ遷移する。
- SCR-START-013: 対応文書のD&DはDND仕様に従う。
- SCR-START-014: 文書を開くためだけに新しいウィンドウを作成しない。
