# mdBook導入画面

## 表示

- SCR-MDBOOKINSTALL-001: mdBook文書を開き、mdBook実行ファイルが利用できない場合に表示できる。
- SCR-MDBOOKINSTALL-002: mdBookが必要となる理由を表示する。
- SCR-MDBOOKINSTALL-003: wingetで導入することを表示する。
- SCR-MDBOOKINSTALL-004: 導入しなくても文書内容へアクセスできることを表示する。

## 操作

- SCR-MDBOOKINSTALL-010: `インストールする` を選択するとwingetによる導入を開始する。
- SCR-MDBOOKINSTALL-011: 導入成功後はmdBookプレビューを利用できる。
- SCR-MDBOOKINSTALL-012: `インストールしない` を選択すると通常MDZ相当の表示へフォールバックできる。
- SCR-MDBOOKINSTALL-013: 外部コマンド実行時に不要なコンソールウィンドウを表示しない。
