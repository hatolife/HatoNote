# mdBook目次編集画面

## 共通

- SCR-TOCEDIT-001: mdBookの目次編集操作から表示する。
- SCR-TOCEDIT-002: 目次編集内容は `SUMMARY.md` に反映する。
- SCR-TOCEDIT-003: 左側GUIの目次編集と右側の `SUMMARY.md` 直接編集を両立する。
- SCR-TOCEDIT-004: GUIと `SUMMARY.md` の内容が矛盾したまま確定しない。

## 項目

- SCR-TOCEDIT-010: 目次へページを追加できる。
- SCR-TOCEDIT-011: 部タイトルを追加できる。
- SCR-TOCEDIT-012: 目次項目の表示名を変更できる。
- SCR-TOCEDIT-013: 目次項目を上へ移動できる。
- SCR-TOCEDIT-014: 目次項目を下へ移動できる。
- SCR-TOCEDIT-015: 目次項目の階層を上げられる。
- SCR-TOCEDIT-016: 目次項目を子階層へ移動できる。
- SCR-TOCEDIT-017: ページを削除せず目次から外せる。
- SCR-TOCEDIT-018: 目次に含まれないページを確認できる。
- SCR-TOCEDIT-019: 目次編集をUndoできる。
- SCR-TOCEDIT-020: 目次編集をRedoできる。
