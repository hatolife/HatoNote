# 投影用画面

## ウィンドウ

- SCR-AUDIENCE-001: 2画面プレゼンテーション時に発表者画面とは別のネイティブウィンドウとして表示する。
- SCR-AUDIENCE-002: ウィンドウをユーザーが任意のモニターへ移動できる。
- SCR-AUDIENCE-003: 発表者側から全画面表示を切り替えられる。
- SCR-AUDIENCE-004: 投影用画面には発表者ノートを送信または表示しない。

## 表示

- SCR-AUDIENCE-010: 発表者側で選択された現在スライドを表示する。
- SCR-AUDIENCE-011: スライドの縦横比を維持する。
- SCR-AUDIENCE-012: スライド外側は資料設定の余白色で表示する。
- SCR-AUDIENCE-013: ページ変更を発表者画面と同期する。

## 操作

- SCR-AUDIENCE-020: Escキーで発表を終了できる。
- SCR-AUDIENCE-021: 右クリックで発表を終了できる。
- SCR-AUDIENCE-022: Fキーまたは発表者側操作で全画面状態を切り替えられる。
- SCR-AUDIENCE-023: 発表者側との接続が終了した場合は投影を継続しない。
