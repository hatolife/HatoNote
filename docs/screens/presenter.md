# 発表者画面

## 開始

- SCR-PRESENTER-001: スライド文書から2画面プレゼンテーションを開始できる。
- SCR-PRESENTER-002: 2画面プレゼンテーション開始時に投影用ウィンドウを別ウィンドウとして開く。
- SCR-PRESENTER-003: 投影用ウィンドウの準備状態を表示する。

## 情報

- SCR-PRESENTER-010: 前のスライドを表示する。
- SCR-PRESENTER-011: 現在のスライドを表示する。
- SCR-PRESENTER-012: 次のスライドを表示する。
- SCR-PRESENTER-013: 最初のページでは前ページが存在しないことを表示する。
- SCR-PRESENTER-014: 最後のページでは次ページが存在しないことを表示する。
- SCR-PRESENTER-015: 現在時刻を表示する。
- SCR-PRESENTER-016: 発表開始からの経過時間を表示する。
- SCR-PRESENTER-017: 経過時間を一時停止できる。
- SCR-PRESENTER-018: 経過時間をリセットできる。
- SCR-PRESENTER-019: 現在ページの発表者ノートを表示する。

## 操作

- SCR-PRESENTER-030: 前ページへ移動できる。
- SCR-PRESENTER-031: 次ページへ移動できる。
- SCR-PRESENTER-032: ページを直接選択できる。
- SCR-PRESENTER-033: 投影用ウィンドウを全画面にする操作を提供する。
- SCR-PRESENTER-034: 投影用ウィンドウを任意のモニターへ移動した後に全画面化できる。
- SCR-PRESENTER-035: 発表を終了できる。
- SCR-PRESENTER-036: 投影側と発表者側の現在ページを同期する。
- SCR-PRESENTER-037: 投影用ウィンドウの全画面表示中はタイトルバーを表示しない。
