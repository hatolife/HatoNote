# ページ追加画面

## 表示

- SCR-PAGEADD-001: 複数ページ文書のページ追加操作から表示する。
- SCR-PAGEADD-002: 単一Markdownでは表示しない。

## 入力

- SCR-PAGEADD-010: 文書内のページ名または相対パスを入力できる。
- SCR-PAGEADD-011: `.md` 拡張子の入力を必須としない。
- SCR-PAGEADD-012: 拡張子が省略された場合は `.md` を自動付与する。
- SCR-PAGEADD-013: 文書内で利用できないパスは追加前に拒否する。
- SCR-PAGEADD-014: 既存ページと衝突するパスは追加前に拒否する。

## 完了

- SCR-PAGEADD-020: 追加すると文書へ新しいMarkdownページを作成する。
- SCR-PAGEADD-021: 追加後は新しいページを選択状態にできる。
- SCR-PAGEADD-022: キャンセルすると文書を変更しない。
