# スライド設定画面

## 資料全体

- SCR-SLIDESET-001: スライド文書から表示する。
- SCR-SLIDESET-002: 資料タイトルを編集できる。
- SCR-SLIDESET-003: 資料テーマを選択できる。
- SCR-SLIDESET-004: スライド外側の余白色を設定できる。
- SCR-SLIDESET-005: 余白色の既定値は白とする。
- SCR-SLIDESET-006: 縦横比を設定できる。
- SCR-SLIDESET-007: `16:9` と `4:3` を選択できる。

## 選択中のページ

- SCR-SLIDESET-010: 一覧表示用のスライド名を編集できる。
- SCR-SLIDESET-011: 本文見出しはMarkdown本文側で編集する。
- SCR-SLIDESET-012: ページレイアウトを選択できる。
- SCR-SLIDESET-013: 標準レイアウトを選択できる。
- SCR-SLIDESET-014: 表紙レイアウトを選択できる。
- SCR-SLIDESET-015: 画像中心レイアウトを選択できる。
- SCR-SLIDESET-016: 左右2列レイアウトを選択できる。
- SCR-SLIDESET-017: ページ背景色を設定できる。
- SCR-SLIDESET-018: 発表者ノートを編集できる。
- SCR-SLIDESET-019: 発表者ノートが文書内に保存され共有時に含まれることを明示する。
