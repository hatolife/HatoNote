# 未保存変更確認画面

## 表示

- SCR-UNSAVED-001: 未保存変更を失う可能性がある操作の前に表示する。
- SCR-UNSAVED-002: 「はい」「いいえ」ではなく実際の操作名を表示する。

## 操作

- SCR-UNSAVED-010: `保存` を選択すると保存後に要求された遷移を続行する。
- SCR-UNSAVED-011: 保存に失敗した場合は要求された遷移を中止する。
- SCR-UNSAVED-012: `破棄` を選択すると未保存変更を破棄して遷移を続行する。
- SCR-UNSAVED-013: `キャンセル` を選択すると遷移を中止して現在文書へ戻る。
