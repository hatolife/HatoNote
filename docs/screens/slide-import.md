# Markdownからスライド追加画面

## 入力

- SCR-SLIDEIMPORT-001: Markdown本文を貼り付けてスライドへ追加できる。
- SCR-SLIDEIMPORT-002: 空行で囲まれた `---` をページ区切りとして扱う。
- SCR-SLIDEIMPORT-003: コードブロック内の `---` をページ区切りとして扱わない。
- SCR-SLIDEIMPORT-004: 空のページを意図せず追加しない。
- SCR-SLIDEIMPORT-005: 入力エラーを画面内に表示する。

## 完了

- SCR-SLIDEIMPORT-010: 取り込みを確定すると分割したページを現在のスライド文書へ追加する。
- SCR-SLIDEIMPORT-011: 追加したページの順序は入力Markdownの順序を維持する。
- SCR-SLIDEIMPORT-012: キャンセルすると文書内容を変更しない。
