# 画面一覧

## 定義

- SCREENSET-001: 開始画面の仕様は `start.md` に定義する。
- SCREENSET-002: メイン画面の仕様は `main.md` に定義する。
- SCREENSET-003: 新規文書作成画面の仕様は `new-document.md` に定義する。
- SCREENSET-004: 設定画面の仕様は `settings.md` に定義する。
- SCREENSET-005: ページ追加画面の仕様は `page-add.md` に定義する。
- SCREENSET-006: mdBook目次編集画面の仕様は `toc-edit.md` に定義する。
- SCREENSET-007: mdBookタイトル編集画面の仕様は `book-title.md` に定義する。
- SCREENSET-008: mdBook設定画面の仕様は `book-settings.md` に定義する。
- SCREENSET-009: 作業データ復旧画面の仕様は `recovery.md` に定義する。
- SCREENSET-010: 未保存変更確認画面の仕様は `unsaved-changes.md` に定義する。
- SCREENSET-011: mdBook導入画面の仕様は `mdbook-install.md` に定義する。
- SCREENSET-012: スライド設定画面の仕様は `slide-settings.md` に定義する。
- SCREENSET-013: Markdownからスライド追加画面の仕様は `slide-import.md` に定義する。
- SCREENSET-014: 1画面プレゼンテーションの仕様は `presentation.md` に定義する。
- SCREENSET-015: 発表者画面の仕様は `presenter.md` に定義する。
- SCREENSET-016: 投影用画面の仕様は `audience.md` に定義する。

## 変更

- SCREENSET-020: 現在の画面仕様は16種類とする。
- SCREENSET-021: 既存画面内の状態追加で表現できる機能のために新しい画面を増やさない。
- SCREENSET-022: 新しい画面が必要な場合は実装前にこの一覧へ追加する。
- SCREENSET-023: 新しい画面が必要な場合は実装前に対応する個別仕様書を作成する。
- SCREENSET-024: オーバーレイまたはダイアログでも独立した操作文脈を持つ場合は画面一覧へ含める。
