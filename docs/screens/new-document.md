# 新規文書作成画面

## 表示

- SCR-NEW-001: 開始画面またはメイン画面から新規文書作成画面を開ける。
- SCR-NEW-002: 新規文書作成画面は既存の作業文書を破棄せずに表示する。
- SCR-NEW-003: 未保存文書から新規作成へ遷移する場合はSAVE仕様に従う。

## 種別

- SCR-NEW-010: 通常MDZを選択できる。
- SCR-NEW-011: mdBook形式のMDZを選択できる。
- SCR-NEW-012: スライド形式のMDZを選択できる。
- SCR-NEW-013: 単一Markdownはこの画面で新規文書種別として作成しない。
- SCR-NEW-014: 各選択肢に用途を短く表示する。
- SCR-NEW-015: 文書種別名と用途が区別できる表示にする。

## 完了

- SCR-NEW-020: 文書種別を選択すると選択した種別の初期文書を生成する。
- SCR-NEW-021: 新規通常MDZは編集を開始できる状態で開く。
- SCR-NEW-022: 新規mdBookはmdBook用テンプレートを持つ。
- SCR-NEW-023: 新規スライドはスライド用テンプレートを持つ。
- SCR-NEW-024: キャンセルすると元の画面状態へ戻る。
