# 新規文書作成

## 表示

- SCR-NEW-001: 新規文書作成UIは開始画面へ統合し、独立した新規文書作成ダイアログを表示しない。
- SCR-NEW-002: メイン画面から新規文書操作を開始した場合も開始画面と同じ新規文書UIを表示する。
- SCR-NEW-003: 未保存文書から新規作成を確定する場合はSAVE仕様に従う。

## 種別

- SCR-NEW-010: 単一Markdownを作成できる。
- SCR-NEW-011: 通常MDZを作成できる。
- SCR-NEW-012: mdBook形式のMDZを作成できる。
- SCR-NEW-013: スライド形式のMDZを作成できる。
- SCR-NEW-014: 各文書種別について空の文書を作成できる。
- SCR-NEW-015: 各文書種別について用途を簡単に説明する初期内容入り文書を作成できる。
- SCR-NEW-016: 文書種別固有の追加テンプレートがある場合はその列へ表示する。
- SCR-NEW-017: テンプレートが存在しない文書種別に空の選択肢を表示しない。
- SCR-NEW-018: 通常MDZの列からフォルダを選択してMDZを生成できる。

## 完了

- SCR-NEW-020: 文書種別またはテンプレートを選択すると新しい文書を生成して編集を開始する。
- SCR-NEW-021: 単一Markdownは通常保存時にMarkdownファイルとして保存できる。
- SCR-NEW-022: 通常MDZは通常保存時にMDZとして保存できる。
- SCR-NEW-023: mdBookはmdBook用の最小構造または説明付きテンプレートを持つ。
- SCR-NEW-024: スライドは1スライド1Markdownファイルの最小構造または説明付きテンプレートを持つ。
