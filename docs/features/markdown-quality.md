# Markdown FormatterとLint

## Formatter

- FORMATTER-001: 編集中のMarkdown本文を明示操作で整形できる。
- FORMATTER-002: Formatterはコードフェンス内の本文を変更しない。
- FORMATTER-003: 行末空白を削除する規則を有効または無効にできる。
- FORMATTER-004: 連続する空行の最大数を設定できる。
- FORMATTER-005: ファイル末尾に改行を付ける規則を有効または無効にできる。
- FORMATTER-006: Formatter実行結果はUndo可能な通常編集として扱う。
- FORMATTER-007: Formatterを自動保存時に暗黙実行しない。
- FORMATTER-008: Formatter設定はHatoNote設定として保持する。

## Lint

- LINT-001: 編集中のMarkdown本文を明示操作でLintできる。
- LINT-002: Lintは本文を変更しない。
- LINT-003: 行末空白の検出を有効または無効にできる。
- LINT-004: 行長の検出を有効または無効にできる。
- LINT-005: 行長の上限文字数を設定できる。
- LINT-006: 見出しレベルの飛びを検出する規則を有効または無効にできる。
- LINT-007: ファイル末尾改行の欠落を検出する規則を有効または無効にできる。
- LINT-008: コードフェンス内では行末空白、行長、見出しレベルの規則を適用しない。
- LINT-009: Lint結果に行番号、規則ID、メッセージを表示する。
- LINT-010: Lint設定はHatoNote設定として保持する。
