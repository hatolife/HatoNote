# ファイルD&D

## 共通

- DND-001: 対応ファイルのD&DをWebViewの既定ナビゲーションへ渡さない。
- DND-002: 対応ファイルのD&Dをブラウザのダウンロード動作として処理しない。
- DND-003: D&Dの結果はドロップ領域と現在の文書状態によって決定する。
- DND-004: 文書を開いていない場合は、対応文書を現在のウィンドウで開く。
- DND-005: 文書を開いている状態で別文書を通常領域へD&Dした場合は、新しいHatoNoteウィンドウで開く。
- DND-006: 単一Markdownを開いている状態で別の単一Markdownを本文領域へD&Dした場合は、新しいHatoNoteウィンドウで開く。
- DND-007: `.mdz` を現在文書のページとして取り込まない。

## ページ一覧へのMarkdown取り込み

- DND-020: 通常MDZのページ一覧へ `.md` をD&Dすると現在文書へページとして取り込む。
- DND-021: mdBookのページ一覧へ `.md` をD&Dすると現在文書へページとして取り込める。
- DND-022: スライドのページ一覧へ `.md` をD&Dすると現在文書へページとして取り込める。
- DND-023: 取り込んだMarkdownは現在のMDZ文書内へコピーする。
- DND-024: ドロップ位置をページ挿入位置として扱う。
- DND-025: 複数のMarkdownファイルを同時に取り込める。
- DND-026: 複数ファイルの相対順序を維持して取り込む。
- DND-027: 取り込み対象外のファイルを現在文書へ混入させない。
