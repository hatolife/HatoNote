# ウィンドウ

## メインウィンドウ

- WINDOW-001: メインウィンドウはフレームレスUIを利用できる。
- WINDOW-002: フレームレスUIでも最小化、最大化、元に戻す、終了を利用できる。
- WINDOW-003: タイトルバーのダブルクリックで最大化状態を切り替える。
- WINDOW-004: 操作部品ではないタイトルバー領域をドラッグしてウィンドウを移動できる。
- WINDOW-005: 左側上部にもウィンドウをドラッグできる領域を確保する。
- WINDOW-006: オーバーレイがタイトルバー操作を覆わない。
- WINDOW-007: 最小ウィンドウサイズでも主要操作へ到達できる。
- WINDOW-008: フレームレスのメインウィンドウは、本文やスクロールバーが表示される高さを含む右端全体から横方向へリサイズできる。

## 複数ウィンドウ

- WINDOW-020: 既に文書を開いている状態で別文書を開く必要がある場合は新しいHatoNoteプロセスまたはウィンドウで開ける。
- WINDOW-021: 2画面プレゼンテーションでは投影用ウィンドウを独立して移動できる。
- WINDOW-022: 投影用ウィンドウを任意のモニター上で全画面化できる。
