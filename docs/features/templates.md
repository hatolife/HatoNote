# テンプレート

## 共通

- TEMPLATE-001: テンプレートは一意なテンプレートIDで識別する。
- TEMPLATE-002: テンプレートは表示名を持つ。
- TEMPLATE-003: テンプレートを使用してもテンプレート定義そのものを変更しない。
- TEMPLATE-004: テンプレート選択は文書種別に応じて利用可能なものだけを表示する。

## ページテンプレート

- TEMPLATE-010: 通常MDZでページ追加時にテンプレートを選択できる。
- TEMPLATE-011: 空ページテンプレートを提供する。
- TEMPLATE-012: メモテンプレートを提供する。
- TEMPLATE-013: 議事録テンプレートを提供する。
- TEMPLATE-014: 仕様書テンプレートを提供する。
- TEMPLATE-015: ページ名を省略した場合でもテンプレート内容からページ名を自動生成しない。
- TEMPLATE-016: テンプレートで作成したページは通常ページと同じ方法で保存・編集できる。

## 将来拡張

- TEMPLATE-020: テンプレートIDを追加することで既存テンプレートを壊さず拡張できる。
- TEMPLATE-021: ユーザー定義テンプレートを追加できる。
- TEMPLATE-022: 文書全体のテンプレートも同じテンプレートID体系で扱う。

## 文書テンプレート

- TEMPLATE-030: 新規通常MDZを文書テンプレートから作成できる。
- TEMPLATE-031: 通常MDZのメモ文書テンプレートを提供する。
- TEMPLATE-032: 通常MDZの議事録文書テンプレートを提供する。
- TEMPLATE-033: 通常MDZの仕様書文書テンプレートを提供する。
- TEMPLATE-034: 文書テンプレートで作成した文書は通常MDZとして保存・編集できる。

## ユーザー定義

- TEMPLATE-040: ユーザー定義テンプレートはHatoNoteのローカル設定領域へ保存する。
- TEMPLATE-041: ユーザー定義テンプレートは文書間で共有して利用できる。
- TEMPLATE-042: ユーザー定義テンプレートには一意なID、表示名、対象、Markdown本文を保存する。
- TEMPLATE-043: 対象は通常MDZのページまたは通常MDZ文書とする。
- TEMPLATE-044: ユーザー定義テンプレートを最大100件保持できる。
- TEMPLATE-045: ユーザー定義テンプレートの表示名を編集できる。
- TEMPLATE-046: ユーザー定義テンプレートのMarkdown本文を編集できる。
- TEMPLATE-047: ユーザー定義テンプレートを削除できる。
- TEMPLATE-048: 内蔵テンプレートはユーザー定義テンプレート管理から変更または削除しない。
- TEMPLATE-049: ユーザー定義ページテンプレートはページ追加画面へ表示する。
- TEMPLATE-050: ユーザー定義文書テンプレートは新規作成画面のMDZ欄へ表示する。
- TEMPLATE-051: テンプレート管理操作だけでは現在開いている文書を変更しない。
