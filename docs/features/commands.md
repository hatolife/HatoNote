# コマンド体系

## 定義

- COMMAND-001: HatoNoteの主要操作を一意なコマンドIDで登録できる。
- COMMAND-002: コマンドは表示名を持つ。
- COMMAND-003: コマンドは現在状態に応じた有効条件を持てる。
- COMMAND-004: 無効なコマンドは実行しない。
- COMMAND-005: 同じコマンドIDを重複登録しない。
- COMMAND-006: ボタン、キーボードショートカット、コマンドパレットは同じコマンド実行経路を利用できる。
- COMMAND-007: コマンドをID列として順番に実行できる基盤を持つ。
- COMMAND-008: コマンド体系はUIと独立して自動テストできる。

## コマンドパレット

- COMMAND-010: `Ctrl+Shift+P` または `Cmd+Shift+P` でコマンドパレットを開ける。
- COMMAND-011: コマンドパレットに登録済みコマンドを表示する。
- COMMAND-012: 入力文字列でコマンド表示名とコマンドIDを絞り込める。
- COMMAND-013: 無効なコマンドは選択できない状態で表示する。
- COMMAND-014: コマンドを選択するとパレットを閉じて実行する。
- COMMAND-015: コマンドパレットを開くだけでは文書内容を変更しない。

## 初期対象

- COMMAND-020: 新規文書画面を開く操作をコマンドとして登録する。
- COMMAND-021: 文書を開く操作をコマンドとして登録する。
- COMMAND-022: 保存操作をコマンドとして登録する。
- COMMAND-023: 名前を付けて保存する操作をコマンドとして登録する。
- COMMAND-024: 文書内検索をコマンドとして登録する。
- COMMAND-025: Markdownチートシートを開く操作をコマンドとして登録する。
- COMMAND-026: 設定画面を開く操作をコマンドとして登録する。
