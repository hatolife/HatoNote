# 文書変換

## 通常MDZからスライド

- CONVERT-001: 通常MDZをスライド形式へ変換できる。
- CONVERT-002: 各Markdown内の有効な `---` をスライドページ区切りとして扱う。
- CONVERT-003: コードブロック内の `---` をページ区切りとして扱わない。
- CONVERT-004: 変換した各スライドに元Markdownファイルを識別できる情報を保持する。
- CONVERT-005: 変換した各スライドに元Markdown内での位置を復元できる情報を保持する。
- CONVERT-006: 変換直後は自動的に保存済み扱いにせず未保存変更として扱う。

## スライドから通常MDZ

- CONVERT-020: スライド形式を通常MDZへ変換できる。
- CONVERT-021: 同じ元Markdown由来の連続ページは `---` を挟んで再結合できる。
- CONVERT-022: 削除されたスライド内容を変換時に勝手に復元しない。
- CONVERT-023: 追加されたスライドを通常MDZ側へ失わず変換する。
- CONVERT-024: 並べ替えられたスライド順序を変換後の文書順へ反映する。
- CONVERT-025: 元情報が残っている範囲では元のMDZ構造を優先して復元する。
- CONVERT-026: 元情報がない新規ページは新しいMarkdownページとして保存できる。
- CONVERT-027: 変換直後は自動的に保存済み扱いにせず未保存変更として扱う。
