# 保存

## 共通

- SAVE-001: 文書内容を変更した場合は未保存状態にする。
- SAVE-002: 保存に成功した場合は未保存状態を解除する。
- SAVE-003: 保存に失敗した場合は未保存状態を維持する。
- SAVE-004: 保存失敗によって既存の保存済み文書を破損させない。
- SAVE-005: 保存処理は可能な範囲で一時ファイルを経由して置換する。
- SAVE-006: 外部変更を検出した場合は無条件に上書きしない。
- SAVE-007: 未保存状態はメイン画面の保存操作から判別できる。
- SAVE-008: 自動保存中であることを理由に通常の閲覧操作を不必要に停止しない。

## 単一Markdown

- SAVE-MARKDOWN-001: 単一Markdownの通常保存は元のMarkdownファイルへ保存する。
- SAVE-MARKDOWN-002: 単一MarkdownをMDZとして名前を付けて保存できる。
- SAVE-MARKDOWN-003: MDZとして保存した場合は元Markdownファイルを意図せず変更しない。

## MDZ

- SAVE-MDZ-001: MDZは文書内のMarkdown、画像、設定、順序情報を1つの `.mdz` へ保存する。
- SAVE-MDZ-002: 保存時に必要な形式情報を保持する。
- SAVE-MDZ-003: 発表者ノートを持つスライド文書を保存した場合はノートもMDZへ保存する。

## 自動保存とバックアップ

- SAVE-020: 自動保存の有効または無効を設定できる。
- SAVE-021: 自動保存間隔を設定できる。
- SAVE-022: 保存前の文書を設定された世代数までバックアップできる。
- SAVE-023: 文書ごとのバックアップ容量上限を設定できる。
- SAVE-024: 異常終了時に復旧できる作業データを保持できる。
