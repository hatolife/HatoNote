# バックアップ履歴と名前付き世代

## 履歴

- HISTORY-001: 保存済みパスを持つ文書ではバックアップ履歴を表示できる。
- HISTORY-002: バックアップ履歴に作成日時を表示する。
- HISTORY-003: バックアップ履歴に自動バックアップと名前付き世代を区別して表示する。
- HISTORY-004: 履歴一覧は現在の文書に対応する履歴だけを表示する。
- HISTORY-005: 履歴を選択して現在の作業状態へ復元できる。
- HISTORY-006: 履歴から復元した状態は未保存変更として扱う。
- HISTORY-007: 履歴から復元するだけでは元の保存済みファイルを上書きしない。

## 名前付き世代

- HISTORY-020: 現在の文書状態を任意の名前を付けて別世代として保存できる。
- HISTORY-021: 名前付き世代保存は通常の文書保存先を変更しない。
- HISTORY-022: 名前付き世代保存は現在の未保存編集内容を含める。
- HISTORY-023: 名前付き世代名は空文字を許可しない。
- HISTORY-024: 名前付き世代は自動バックアップの世代削除設定とは別に保持する。
- HISTORY-025: 名前付き世代には一意な履歴IDを付ける。

## 将来拡張

- HISTORY-030: 履歴IDを使って現在状態と履歴状態の差分比較を追加できる構造とする。
