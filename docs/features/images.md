# 画像

## 貼り付け

- IMAGE-001: クリップボード画像をMarkdown編集中に貼り付けられる。
- IMAGE-002: MDZ文書では貼り付け画像を文書内へ保存できる。
- IMAGE-003: 保存した画像への相対Markdownリンクを本文へ挿入できる。
- IMAGE-004: 画像保存先を設定できる。
- IMAGE-005: 画像ファイル名規則を設定できる。
- IMAGE-006: 同名画像を意図せず上書きしない。
- IMAGE-007: Undoによって本文中の画像リンクが消えても、画像本体を即座に破壊的削除しない。

## 表示

- IMAGE-010: PNGを表示できる。
- IMAGE-011: JPEGを表示できる。
- IMAGE-012: GIFを表示できる。
- IMAGE-013: WebPを表示できる。
- IMAGE-014: SVGを表示できる。
- IMAGE-015: 単一Markdownの相対画像は元Markdownファイルのディレクトリを基準に解決する。
- IMAGE-016: MDZ内画像は文書コンテナ内のパスを基準に解決する。
