# ページナビゲーション

## クイックオープン

- NAV-001: 複数ページ文書ではクイックオープンを利用できる。
- NAV-002: `Ctrl+P` または `Cmd+P` でクイックオープンを開ける。
- NAV-003: クイックオープンには現在文書のMarkdownページを表示する。
- NAV-004: 入力文字列でページパスを大文字小文字を区別せず絞り込める。
- NAV-005: クイックオープンからページを選択するとそのページへ移動する。
- NAV-006: クイックオープンを開くだけでは文書内容を変更しない。
- NAV-007: 単一Markdownではクイックオープンを表示しない。

## 移動履歴

- NAV-010: ページ間移動を文書ごとのナビゲーション履歴として保持する。
- NAV-011: 戻る操作で直前に表示していたページへ移動できる。
- NAV-012: 戻る操作後は進む操作で元のページへ戻れる。
- NAV-013: 戻った後に通常のページ移動を行うと進む履歴を破棄する。
- NAV-014: ナビゲーション履歴は最大100件保持する。
- NAV-015: 文書を切り替えた場合はナビゲーション履歴を初期化する。
- NAV-016: ナビゲーション履歴にはページごとのスクロール位置を保持する。
- NAV-017: `Alt+Left` で戻る操作を実行できる。
- NAV-018: `Alt+Right` で進む操作を実行できる。
- NAV-019: 戻るまたは進む履歴が無い場合は対応操作を無効表示する。
