# 文書内検索

## 対象

- SEARCH-001: 文書を開いている場合に文書内検索を開始できる。
- SEARCH-002: 文書内検索は現在文書に含まれるMarkdownページを対象とする。
- SEARCH-003: 単一Markdownでは現在のMarkdownファイルだけを対象とする。
- SEARCH-004: 通常MDZ、mdBook、slidesでは文書内の全Markdownページを対象とする。
- SEARCH-005: 検索開始前に現在の未保存編集内容を検索対象へ反映する。

## 操作

- SEARCH-010: 検索UIをボタンから開ける。
- SEARCH-011: `Ctrl+F` または `Cmd+F` で検索UIを開ける。
- SEARCH-012: 検索文字列を変更すると検索結果を更新する。
- SEARCH-013: 検索結果にページ名、行番号、該当行の内容を表示する。
- SEARCH-014: 検索結果を選択すると該当ページへ移動する。
- SEARCH-015: 編集中に検索結果を選択した場合は可能な範囲で該当文字列を選択する。
- SEARCH-016: 空の検索文字列では検索結果を表示しない。
- SEARCH-017: 検索は既定で大文字小文字を区別しない。
