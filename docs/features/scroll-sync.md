# スクロール同期

## 共通

- SCROLL-001: プレビュー、Markdown内蔵エディター、WYSIWYG内蔵エディター、Neovim、TOCの現在位置を同じ文書位置として扱える。
- SCROLL-002: 同期処理によって無限の相互スクロールを発生させない。
- SCROLL-003: ページを切り替えた直後に同期処理で不必要な位置へ飛ばさない。
- SCROLL-004: 同期元がユーザー操作かプログラム操作かを区別できる設計とする。

## プレビュー

- SCROLL-010: プレビューをスクロールすると対応する見出しをTOCでハイライトする。
- SCROLL-011: プレビューをスクロールすると、編集状態では対応位置へエディターを追従させられる。

## 内蔵エディター

- SCROLL-020: Markdown内蔵エディターをスクロールするとプレビューを対応位置へ追従させる。
- SCROLL-021: Markdown内蔵エディターの位置変更に合わせてTOCハイライトを更新する。
- SCROLL-022: WYSIWYG内蔵エディターをスクロールするとプレビューを対応位置へ追従させる。
- SCROLL-023: WYSIWYG内蔵エディターの位置変更に合わせてTOCハイライトを更新する。

## Neovim

- SCROLL-030: Neovimの現在位置をプレビューへ反映できる。
- SCROLL-031: Neovimの現在位置に合わせてTOCハイライトを更新できる。

## TOC

- SCROLL-040: TOC項目を選択すると本文の対応位置へ移動する。
- SCROLL-041: TOC選択で文書全体を再読み込みしない。
- SCROLL-042: 現在位置のTOC項目が見えなくなった場合はサイドバーを必要に応じて追従スクロールする。
