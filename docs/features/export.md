# エクスポート

## 共通

- EXPORT-001: 現在の文書を単一HTMLへエクスポートできる。
- EXPORT-002: 現在の文書をPDFへエクスポートできる。
- EXPORT-003: エクスポート前に現在の未保存編集内容を取り込む。
- EXPORT-004: エクスポートしても通常の保存先を変更しない。
- EXPORT-005: エクスポートしても未保存状態を保存済みに変更しない。
- EXPORT-006: エクスポート先はユーザーが指定できる。
- EXPORT-007: エクスポート失敗時に元文書を変更しない。

## 単一HTML

- EXPORT-010: 単一HTMLは追加ファイルを必要とせず1ファイルだけで閲覧できる。
- EXPORT-011: 文書内画像をdata URIとして単一HTMLへ埋め込む。
- EXPORT-012: 通常MDZとmdBookではMarkdownページを文書順に出力する。
- EXPORT-013: 単一Markdownでは現在のMarkdown本文を1ページとして出力する。
- EXPORT-014: スライドではスライド順序とレイアウトを維持して出力する。
- EXPORT-015: 文書内MarkdownへのリンクはエクスポートHTML内の対象ページへ移動できる。
- EXPORT-016: 見出しリンクはエクスポートHTML内でページごとに衝突しないIDへ変換する。

## PDF

- EXPORT-020: PDFは単一HTMLと同じMarkdown変換結果を元に生成する。
- EXPORT-021: PDFには文書内画像を含める。
- EXPORT-022: スライド文書はスライドごとに改ページする。
- EXPORT-023: PDF生成に必要な実行環境が利用できない場合は理由を表示する。
