# 最近開いた文書

## 記録

- RECENT-001: パスを持つ文書を正常に開いた場合は最近開いた文書へ記録する。
- RECENT-002: 同じ文書を再度開いた場合は重複させず先頭へ移動する。
- RECENT-003: 最近開いた文書は最大10件保持する。
- RECENT-004: 最近開いた文書の記録はHatoNoteのローカル環境に保持する。

## 開始画面

- RECENT-010: 開始画面に最近開いた文書を表示する。
- RECENT-011: 最近開いた文書がない場合は一覧を表示しない。
- RECENT-012: 最近開いた文書から選択すると現在のウィンドウで開く。
- RECENT-013: 最近開いた文書にはファイル名を主表示する。
- RECENT-014: 最近開いた文書の完全パスを確認できる。
