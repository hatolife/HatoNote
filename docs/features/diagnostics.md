# 診断ログ

## 保存

- LOG-001: HatoNoteは診断ログをアプリデータ領域の `HatoNote.log` に保存する。
- LOG-002: 診断ログを書き込めない場合でもHatoNoteの起動と文書操作を妨げない。
- LOG-003: 診断ログにはアプリケーションエラーとNeovimの起動・継続利用失敗を記録する。

## 容量

- LOG-010: 診断ログは固定上限を持ち、無制限に増加しない。
- LOG-011: 診断ログが上限を超える場合は古い内容から破棄して新しい内容を保持する。

## 表示

- LOG-020: 下部ステータスバーのステータスを選択すると、診断ログを画面下部から開ける。
- LOG-021: 診断ログ表示には `HatoNote.log` の現在の内容を表示し、開いた直後は最新のログを確認できる位置にする。
- LOG-022: 診断ログ表示とステータスからマウスポインターが離れた状態が一定時間続いた場合は、診断ログ表示を自動的に閉じる。
- LOG-023: 診断ログ表示は明示的な閉じる操作でも閉じられる。
