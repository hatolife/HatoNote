# マクロ

## 定義

- MACRO-001: マクロは一意なID、表示名、コマンドID列を持つ。
- MACRO-002: マクロはHatoNoteのローカル環境に保存する。
- MACRO-003: マクロは最大100件保持する。
- MACRO-004: 1つのマクロは最大100コマンドとする。
- MACRO-005: マクロはCommand体系のコマンドIDだけを保存する。
- MACRO-006: マクロ保存時に文書内容そのものを複製しない。

## 記録

- MACRO-010: マクロ記録を開始できる。
- MACRO-011: 記録中にCommand経由で実行した操作を実行順に記録する。
- MACRO-012: マクロ管理操作そのものは記録しない。
- MACRO-013: 記録停止時に名前を付けて保存できる。
- MACRO-014: コマンドを1件も記録していないマクロは保存しない。
- MACRO-015: 記録中であることをユーザーが確認できる。

## 再生

- MACRO-020: 保存済みマクロを実行できる。
- MACRO-021: マクロは保存されたコマンド順に実行する。
- MACRO-022: 無効状態のコマンドは実行せず次のコマンドへ進む。
- MACRO-023: コマンド実行でHatoNote内のダイアログが開いた場合は、そのダイアログが閉じるまで次のコマンドへ進まない。
- MACRO-024: 存在しないコマンドIDを含むマクロはその位置でエラーを表示して停止する。
- MACRO-025: マクロ再生中のコマンドを新しいマクロ記録へ追加しない。

## 管理

- MACRO-030: 保存済みマクロの名前とコマンド数を一覧表示する。
- MACRO-031: 保存済みマクロを削除できる。
- MACRO-032: マクロ管理画面をCommand Paletteから開ける。
