# スライド形式

## 判別

- FORMAT-SLIDES-001: スライド定義ファイルを持つMDZをスライド形式として識別できる。
- FORMAT-SLIDES-002: スライド形式も拡張子は `.mdz` を使用する。

## ページ

- FORMAT-SLIDES-010: 各スライドはMarkdown本文を持つ。
- FORMAT-SLIDES-011: スライド順序を文書内に保持する。
- FORMAT-SLIDES-012: スライドごとに一覧表示名を保持できる。
- FORMAT-SLIDES-013: スライドごとにレイアウトを保持できる。
- FORMAT-SLIDES-014: スライドごとに背景設定を保持できる。
- FORMAT-SLIDES-015: スライドごとに発表者ノートを保持できる。

## 資料設定

- FORMAT-SLIDES-020: 資料タイトルを保持できる。
- FORMAT-SLIDES-021: テーマを保持できる。
- FORMAT-SLIDES-022: 余白色を保持できる。
- FORMAT-SLIDES-023: 縦横比を保持できる。
- FORMAT-SLIDES-024: フォントファミリーを保持できる。
- FORMAT-SLIDES-025: 本文とH1からH5の文字サイズを保持できる。
- FORMAT-SLIDES-026: 上下左右の余白設定を保持できる。

## 既定値

- FORMAT-SLIDES-030: 本文文字サイズの既定値は20を基準とする。
- FORMAT-SLIDES-031: H1文字サイズの既定値は42を基準とする。
- FORMAT-SLIDES-032: H2文字サイズの既定値は28を基準とする。
- FORMAT-SLIDES-033: H3文字サイズの既定値は26を基準とする。
- FORMAT-SLIDES-034: H4文字サイズの既定値は24を基準とする。
- FORMAT-SLIDES-035: H5文字サイズの既定値は22を基準とする。
- FORMAT-SLIDES-036: 余白色の既定値は白とする。

## レンダリング

- FORMAT-SLIDES-040: 編集プレビューとプレゼンテーションは可能な限り同じレンダリング規則を使用する。
- FORMAT-SLIDES-041: 画面サイズに応じてスライド全体を縦横比を維持して拡大縮小する。
- FORMAT-SLIDES-042: スライド枠外の内容は編集プレビューでは確認できる。
