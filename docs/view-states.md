# 表示状態

## 共通

- VIEW-001: メイン画面の表示状態は `view`、`edit`、`split` を定義する。
- VIEW-002: 表示状態は文書種別とは独立して管理する。
- VIEW-003: 表示状態は編集エンジンとは独立して管理する。
- VIEW-004: 表示状態を切り替えても文書内容を変更しない。
- VIEW-005: 表示状態を切り替えても未保存状態を不必要に変更しない。
- VIEW-006: 表示状態の現在値をUIから判別できる。

## view

- VIEW-010: `view` では文書のプレビューを主領域に表示する。
- VIEW-011: `view` では本文エディターを通常操作対象として表示しない。
- VIEW-012: 既存文書を開いた直後の既定表示状態は `view` とする。

## edit

- VIEW-020: `edit` では選択中の編集エンジンで本文を編集できる。
- VIEW-021: `edit` では必要に応じてプレビューを補助表示できる。
- VIEW-022: 新規作成した通常MDZは編集を開始しやすい状態へ遷移できる。

## split

- VIEW-030: `split` ではエディターとプレビューを同時に表示する。
- VIEW-031: `split` ではエディターとプレビューのスクロール位置を同期できる。
- VIEW-032: `split` で片側を更新した場合、もう片側へ編集内容を反映する。
