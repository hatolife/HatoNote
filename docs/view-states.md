# 操作状態とペイン配置

## 共通

- VIEW-001: 操作状態は `viewing` と `editing` を定義する。
- VIEW-002: ペイン配置は `editor`、`split`、`preview` を定義する。
- VIEW-003: 操作状態は文書種別とは独立して管理する。
- VIEW-004: ペイン配置は文書種別とは独立して管理する。
- VIEW-005: 編集エンジンは操作状態とペイン配置とは独立して管理する。
- VIEW-006: 操作状態またはペイン配置を切り替えても文書内容を変更しない。
- VIEW-007: 操作状態またはペイン配置を切り替えても未保存状態を不必要に変更しない。
- VIEW-008: 現在の操作状態をUIから判別できる。
- VIEW-009: 編集中は現在のペイン配置をUIから判別できる。

## viewing

- VIEW-010: `viewing` では本文を変更する編集操作を無効にする。
- VIEW-011: `viewing` ではプレビューを主表示する。
- VIEW-012: 既存文書を開いた直後の既定操作状態は `viewing` とする。
- VIEW-013: `viewing` へ切り替えても未保存変更を破棄しない。

## editing

- VIEW-020: `editing` では選択中の編集エンジンで本文を変更できる。
- VIEW-021: `editing` では `editor`、`split`、`preview` のペイン配置を切り替えられる。
- VIEW-022: 新規通常MDZは編集を開始できる操作状態で開く。
- VIEW-023: `editing` から `viewing` へ戻った後、再び `editing` にした場合は以前のペイン配置を再利用できる。

## editor

- VIEW-030: `editor` ではエディターを主表示する。
- VIEW-031: `editor` でも現在の編集内容をプレビュー生成へ反映できる。

## split

- VIEW-040: `split` ではエディターとプレビューを同時表示する。
- VIEW-041: `split` ではエディターとプレビューのスクロール位置を同期できる。
- VIEW-042: `split` で片側を更新した場合、もう片側へ編集内容を反映する。

## preview

- VIEW-050: `preview` ではプレビューを主表示する。
- VIEW-051: `editing` のまま `preview` を選択しても編集セッション自体は終了しない。
