# 用語

## 製品

- TERM-001: `HatoNote` はアプリケーション全体を指す。
- TERM-002: `MDZ` はMarkdownと画像等をZIPコンテナへ格納する `.mdz` 文書を指す。

## 文書

- TERM-010: 文書はHatoNoteで現在開いている1つの編集対象を指す。
- TERM-011: 文書種別は文書の構造と利用可能な能力を表す。
- TERM-012: 文書種別は `markdown`、`mdz`、`mdbook`、`slides` を定義する。
- TERM-013: `markdown` は単一の `.md` または `.markdown` ファイルを指す。
- TERM-014: `mdz` は通常の複数ページMDZ文書を指す。
- TERM-015: `mdbook` は `book.toml` と `SUMMARY.md` を持つMDZ文書を指す。
- TERM-016: `slides` はスライド定義を持つMDZ文書を指す。

## 表示

- TERM-020: 表示状態はメイン画面で本文領域をどの構成で表示するかを表す。
- TERM-021: `view` はプレビューを表示する状態を指す。
- TERM-022: `edit` はエディターを主に表示する状態を指す。
- TERM-023: `split` はエディターとプレビューを同時表示する状態を指す。
- TERM-024: 表示状態と文書種別をまとめて「モード」と呼ばない。

## 編集

- TERM-030: 編集エンジンはMarkdown本文を編集する実装を指す。
- TERM-031: `builtin` はHatoNote内蔵エディターを指す。
- TERM-032: `neovim` は外部NeovimをHatoNoteから利用する編集エンジンを指す。
- TERM-033: 編集エンジンと表示状態を別々に管理する。

## 画面

- TERM-040: 画面はユーザーが明確に異なる操作文脈として認識するUI状態を指す。
- TERM-041: オーバーレイまたはダイアログで表示される操作も、独立した仕様が必要な場合は画面仕様として定義する。
- TERM-042: 画面仕様を分割することは、実装上のトップレベルウィンドウ数を増やすことを意味しない。
