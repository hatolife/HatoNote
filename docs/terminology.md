# 用語

## 製品

- TERM-001: `HatoNote` はアプリケーション全体を指す。
- TERM-002: `MDZ` はMarkdownと画像等をZIPコンテナへ格納する `.mdz` 文書を指す。

## 文書

- TERM-010: 文書はHatoNoteで現在開いている1つの編集対象を指す。
- TERM-011: 文書種別は文書の構造と利用可能な能力を表す。
- TERM-012: 文書種別は `markdown`、`mdz`、`mdbook`、`slides` を定義する。
- TERM-013: `markdown` は単一の `.md` または `.markdown` ファイルを指す。
- TERM-014: `mdz` は通常の複数ページMDZ文書を指す。
- TERM-015: `mdbook` は `book.toml` と `SUMMARY.md` を持つMDZ文書を指す。
- TERM-016: `slides` はスライド定義を持つMDZ文書を指す。

## 操作状態

- TERM-020: 操作状態は文書を閲覧しているか編集しているかを表す。
- TERM-021: `viewing` は文書内容を変更する編集操作を無効にした状態を指す。
- TERM-022: `editing` は文書内容を変更する編集操作を有効にした状態を指す。
- TERM-023: 操作状態と文書種別をまとめて「モード」と呼ばない。

## ペイン配置

- TERM-030: ペイン配置はメイン画面の本文領域にエディターとプレビューをどう配置するかを表す。
- TERM-031: `editor` はエディターを主表示する配置を指す。
- TERM-032: `split` はエディターとプレビューを同時表示する配置を指す。
- TERM-033: `preview` はプレビューを主表示する配置を指す。
- TERM-034: ペイン配置は操作状態とは独立して管理する。

## 編集

- TERM-040: 編集エンジンはMarkdown本文を編集する実装を指す。
- TERM-041: `builtin` はHatoNote内蔵エディターを指す。
- TERM-042: `neovim` は外部NeovimをHatoNoteから利用する編集エンジンを指す。
- TERM-043: 編集エンジンと操作状態とペイン配置を別々に管理する。

## 画面

- TERM-050: 画面はユーザーが明確に異なる操作文脈として認識するUI状態を指す。
- TERM-051: オーバーレイまたはダイアログで表示される操作も、独立した仕様が必要な場合は画面仕様として定義する。
- TERM-052: 画面仕様を分割することは、実装上のトップレベルウィンドウ数を増やすことを意味しない。
